PROJE AMACI
-----------
Kullanıcının doğal dilde (metin veya sesle) sorduğu soruları anlayıp
doğru fonksiyonu çağıran, Excel'den gerçek veri döndüren ve
doğal dilde Türkçe yanıt veren bir AI chat sistemi kurmak.
Hedef: Global B2B satış, GDPR uyumlu, internet bağlantısı gerektirmez.

-----------------------

- Ollama 0.24.0 (local LLM sunucusu) — http://localhost:11434
- Model: llama3.1 (tool calling destekliyor)
- Kütüphaneler: fastapi, uvicorn, requests, pandas, openpyxl, openai-whisper, python-multipart
- VS Code (editor)

MAIN.PY — GÜNCEL ROUTE FONKSİYONU YAPISI
-----------------------------------------
- tool_choice: "required" → model her zaman tool çağırır
- İkinci Ollama çağrısı (use_tools=False) → tool sonucunu doğal dile çevirir
- JSON kontrolü → final boşsa veya JSON içeriyorsa direkt tool sonucu gösterilir
- history temiz tutulur (role: assistant, tool sırasıyla)

KARŞILAŞILAN SORUNLAR VE ÇÖZÜMLER
-----------------------------------
1. KeyError: 'message'
   → result.get("message", {}) kullanıldı

2. llama3 does not support tools
   → llama3 → llama3.1 olarak değiştirildi

3. Model tool kullanmak yerine kendi cevap üretti
   → tool_choice: "required" eklendi

4. Model hallüsinasyon yaptı
   → get_all_stock eklendi, sistem prompt güçlendirildi
   → JSON kontrolü: final boşsa tool sonucu direkt gösterilir

5. Form data requires python-multipart
   → pip3 install python-multipart

6. ffmpeg bulunamadı (ses için)
   → brew install ffmpeg

7. Address already in use
   → lsof -ti:8000 | xargs kill -9

8. Ollama güncelleme (brew çalışmadı)
   → curl -fsSL https://ollama.com/install.sh | sh

9. JSON ekrana yansıdı
   → route() içinde JSON kontrolü eklendi
   → final içinde { varsa direkt fn_results göster
